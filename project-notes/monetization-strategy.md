# Monetization Strategy (Focamai)

## Core Principle
- Compete with Amazon on **less friction + more clarity**
- Never interrupt the core search flow
- Charge only for **certainty**, not usage

---

## User Psychology
- Users leave instantly if you add friction beyond the results
- There is no curiosity or hesitation — they act or they leave

---

## Core Insight
- Hook = "don't overpay"
- Value = "don't choose wrong"

**Final mental model:**
- Get them to pay for a moment of doubt (price uncertainty)
- Keep them because the experience is better (confidence in their choice)
